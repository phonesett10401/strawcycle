# ChatGPT image prompts (video transitions)

Eight images: four scenes, each wide and tall. Every prompt is complete on its own; paste it into ChatGPT as is.

- Save them in `video/chatgpt/` with the names below. Do **not** save over `images/scene-N.jpg` (those are the film's own fallback stills).
- ChatGPT makes 3:2 / 2:3 images; that's fine, they get cropped to 16:9 / 9:16 for the video.
- If text or a logo appears: "Same image, but remove all text and logos." If it looks purple: "Same image, warmer: straw gold and amber, no purple or lavender." To keep the packaging consistent, make the scenes in one chat and say "Use the exact same packaging, cutlery, chopsticks and drinking straw as the previous image."
